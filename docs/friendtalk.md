# 친구톡 (FriendTalk) 개념 정리

> 이 프로젝트(sprint-kakao)에서 **채널이 친구에게 능동적으로 보내는 메시지**의 근거 문서.
> 코드 계약은 `packages/contract/src/friendtalk.ts`, 빌더는 `apps/playground`의 친구톡 탭.
> 출처: Kakao i Connect Message(비즈메시지 API), 카카오 비즈니스 가이드.

## 한 줄 정의

**친구톡** = 카카오톡 채널을 **친구 추가한 사용자**에게, 채널이 **먼저(push)** 보내는
정보·광고성 메시지. 카카오 **비즈메시지** 제품군에 속한다.

## 다른 메시지와의 구분 (가장 헷갈리는 지점)

| 구분 | 방향 | 대상 | 제품 / API | 이 프로젝트 |
|---|---|---|---|---|
| **챗봇 스킬 응답** | 사용자 발화에 **응답** | 채널에서 말 건 사용자 | 오픈빌더 스킬 (`SkillResponse`) | `apps/server` /skill |
| **친구톡** | 채널이 **먼저 발송(push)** | **채널 친구** | 비즈메시지 (FT) | `friendtalk.ts` + 빌더 |
| **알림톡** | 채널이 먼저 발송 | 친구 아니어도(전화번호) | 비즈메시지 (AT) | (추후) |
| developers 메시지 | 앱이 발송 | 나/카톡 친구(개인) | developers.kakao.com | 공유/개인용(보조) |

핵심: **친구톡은 developers.kakao.com 메시지 API가 아니다.** 개인용 "나에게/친구에게
보내기"와 완전히 다른 **비즈메시지** 제품이며, 별도 계약·발신프로필이 필요하다.

## 친구톡 vs 알림톡

| | 친구톡 | 알림톡 |
|---|---|---|
| 대상 | **채널 친구만** | 친구 아니어도 발송(전화번호) |
| 성격 | 정보 **+ 광고성 가능** | **정보성만** |
| 템플릿 사전승인 | 불필요(콘텐츠 심사) | **필요**(template_code) |
| 표기 | 광고 시 `(광고)` + 수신거부 | 없음 |
| 용도 | 프로모션·소식·리마인드 | 주문/예약/인증 등 거래 알림 |

## 받을 수 있는 사람 = 채널 친구

- 사용자가 채널을 **친구 추가**해야 친구톡 수신 대상이 된다.
- 발송은 **전화번호(수신번호) 기준**. (챗봇의 botUserKey와 다른 식별 체계)

## 발송에 필요한 것 (온보딩)

친구톡은 코드만으로 못 보낸다. 아래가 선행되어야 한다:

1. **카카오톡 채널** 개설 → 비즈니스 채널 인증
2. **비즈메시지 이용 신청** — 경로 택1
   - 카카오 i 커넥트 메시지(직접 계약), 또는
   - 대행사(NHN Cloud, Solapi, 알리고, Bizgo 등)
3. **발신프로필(sender_key) 등록** — 채널과 연결된 발송 키
4. 발송 API 인증(oauthToken 등, 경로별 상이)

> 현재 이 프로젝트: **발신프로필 미보유** → 실제 발송 불가. 빌더로 **콘텐츠 포맷만
> 선구현**해 두고, 온보딩 후 발송 봉투에 감싸 연결한다. (C4 모델 openQuestion q3)

## 메시지 구조

### 발송 요청(봉투) — 경로별로 다름, 대표 형태

```json
{
  "message_type": "FT",
  "sender_key": "<발신프로필 키>",
  "phone_number": "8201012341234",
  "message": "본문 (최대 1000자)",
  "fall_back_yn": false
}
```

- `message_type`: `"FT"` 고정
- `sender_key`: 발신프로필 키 (필수)
- `phone_number`: 국가코드(82) 포함
- `message`: 본문 텍스트, **≤ 1000자**
- `fall_back_yn` / `fall_back_message_type`(`SM`=SMS/`LM`=LMS): 친구톡 실패 시 문자 대체

### 콘텐츠 부가 요소 (이 프로젝트가 다루는 부분)

- **image**: `img_url`(필수), `img_link`(선택, 클릭 이동)
- **buttons**(최대 5): `name` + `type`
  - `WL` 웹링크(`url_mobile`/`url_pc`)
  - `AL` 앱링크(`scheme_android`/`scheme_ios`)
  - `BK` 봇키워드, `MD` 메시지전달
- 고급형(추후): 와이드 이미지, 와이드 리스트, 캐러셀, 아이템 리스트
  → `friendtalk.ts`의 `DEFERRED_FRIENDTALK`

## 광고성 규제 (친구톡 특유)

- 광고성 메시지는 본문에 **`(광고)` 표기** + **무료 수신거부** 안내가 붙는다.
- **야간 발송 제한**: 광고성은 20:00~08:00 발송 금지(정보성 제외).
- 콘텐츠 정책 심사 대상.
